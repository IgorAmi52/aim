# aim logo

The wordmark is "aim" set in [VT323](https://fonts.google.com/specimen/VT323) (SIL Open Font License), outlined to paths, with the whole i in purple.

| File | Use |
|---|---|
| `aim-wordmark.svg` / `.png` | Wordmark on light backgrounds |
| `aim-wordmark-on-dark.svg` / `.png` | Wordmark on dark backgrounds |
| `aim-app-tile.svg` / `.png` | Square app tile with the wordmark (plugin icon, Slack, Loom) |
| `aim-icon.svg` / `.png` | Square tile with the purple i alone (favicon, small avatars) |

## Colours

| Role | On light | On dark |
|---|---|---|
| Ink | `#16142A` | `#F1EFFA` |
| Purple (the i) | `#5B2BD6` | `#A68CFF` |
| Tile background | | `#14121F` |
